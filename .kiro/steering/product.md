# Product Overview

## Purpose
Everything Claude Code is a comprehensive collection of production-ready configurations, agents, skills, hooks, commands, and rules for AI-assisted development. Originally built for Claude Code, this repository now provides Kiro-compatible configurations to help developers build better software faster.

## Target Users
- Developers using Kiro IDE for AI-assisted development
- Teams wanting to standardize their AI development workflows
- Engineers building production applications with AI assistance
- Open source contributors improving AI development patterns

## Key Features
- **Custom Agents**: Specialized AI agents for planning, code review, security analysis, TDD, and more
- **Steering Files**: Project context and coding standards that guide AI behavior
- **Automation Hooks**: Event-driven workflows for testing, formatting, and quality checks
- **MCP Integrations**: Connections to external services (GitHub, databases, deployment platforms)
- **Battle-Tested Patterns**: Configurations refined over 10+ months of production use

## Business Goals
1. Enable developers to build production-quality code with AI assistance
2. Reduce repetitive tasks through intelligent automation
3. Maintain code quality and security standards consistently
4. Share knowledge and patterns with the developer community
5. Support both individual developers and teams

## Success Metrics
- Code quality maintained at production standards
- Development velocity increased through automation
- Security vulnerabilities caught before deployment
- Test coverage consistently above 80%
- Community adoption and contributions
